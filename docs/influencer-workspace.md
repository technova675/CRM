# Influencer Marketing (Section 18)

Open **Execution → Influencers**, or `/influencers`.

- **Creator database** stores creator/platform/profile URLs, follower and engagement figures, category, geography, audience notes, pricing/packages in INR, email/phone, availability, prior campaign notes, performance rating and dated source details. Blanks mean unknown; zero means an explicitly recorded zero. Existing profiles remain readable and are labelled legacy/unverified until source information is entered. This workspace does not independently verify a profile or fetch live follower counts.
- **AI matching** selects a client campaign and explicit requirements. Saved-record ranking provides a transparent weighted fit score; no external industry benchmarks are assumed. Platform, quoted price-per-post cap, follower range and engagement minimum are hard filters, including missing required figures. Category/location/format/audience-note keyword overlap contribute explained fit points. Creator location is not audience geography. No configured scoring requirements produces an unknown score, not 100%. AI adds labelled inference and risks for up to 20 eligible candidates. Up to 100 results are displayed from the full database. **Rank saved data** is the explicit non-AI alternative.
- Matching results persist on the campaign. Shortlisting requires current requirements and unchanged creator/campaign data. It creates one engagement per campaign/creator and updates campaign creator IDs atomically. The quote cap compares the stored per-post quote; it does not estimate a multi-deliverable package or total campaign spend. Quoted pricing is not an agreed fee. Unknown commitments remain unknown.
- **Campaign pipeline** tracks Shortlisted → Outreach → Negotiation → Contracted → Content Submitted → Approved → Live → Paid. The collaboration editor stores negotiations, explicit agreed fees, dated deliverables/completion, submitted content URL, human content approval, human-recorded live URL, payment amount/reference/due date, communication log and dated performance snapshots.
- Contracted and later stages require a fee and deliverables. Content approval requires saved submitted content. Changing the submitted URL invalidates approval and old performance. Live requires an approved submitted URL plus human-recorded live URL. Paid requires full recorded payment. Payment status is derived from recorded amounts; no bank transfer occurs.
- **Outreach** can generate a personalized AI draft using saved brand/campaign/creator information. Review and send using your chosen external channel; explicitly log actual contact/replies here. Neither drafting nor a local automation setting sends a message. Communication status is human-reported, not a delivery receipt.
- **Performance** shows dated source records and calculated CPE/CPV/CPA/ROAS with unknown denominators preserved. Saving replaces a single cumulative snapshot instead of adding overlapping figures. Undated legacy `results` are not treated as new measured performance.

The workspace uses the existing server AI provider/fallback, account-scoped Supabase `crm_libraries` JSON storage, revision checks and idempotent operations. No SQL migration or new API keys are needed. Profiles, shortlists and tracking are shared across laptops signed in to the same account. Managed records cannot be overwritten by an older tab's generic CRM sync. Creator records with campaign history cannot be deleted; mark them unavailable to preserve history.

Verification: `node --test scripts/influencer.test.mjs`; `node --env-file=.env.local scripts/influencer-integration.mjs`. Set `INFLUENCER_TEST_LIVE=1` for actual AI matching/outreach-draft verification. Browser checks use `scripts/influencer-ui.mjs`. All fixtures use disposable accounts and send no messages or payments.
